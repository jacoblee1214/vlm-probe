# vlm-probe

사내 공용 추론 서버에 올라간 영상 인식 모델에게 질문을 던지는 도구와, 그 모델이 **무엇까지
볼 수 있고 무엇을 놓치는지** 측정하는 도구입니다.

측정 결과는 `results/` 아래에 **모델 이름과 측정한 날짜를 파일명에 넣어** 보관합니다. 모델을
바꾸거나 서버를 다른 설정으로 다시 띄우면 수치가 달라지므로, 파일 맨 위에 적힌 조건이 지금
서버 상태와 같은지 확인하고 쓰십시오.

## 먼저 알아두실 점

측정으로 확인된 사항입니다. 근거는 [최신 측정 결과](results/2026-09-18_qwen3.8-27b.md)에
있습니다.

1. **영상은 20초 이내로 잘라서 넣으십시오.** 모델은 영상을 통째로 보지 않고 사진을 몇 장
   뽑아서 봅니다. 20초까지는 초당 2장을 읽지만, 그보다 길면 읽는 장수가 줄어듭니다. 180초
   영상은 초당 0.48장까지 떨어집니다.
2. **0.5초보다 짧은 순간을 찾는 데 쓰지 마십시오.** 물건이 닿는 순간이나 미끄러지는 순간처럼
   짧게 일어나는 일은 뽑힌 사진에 담기지 않아서 아예 잡히지 않습니다.
3. **질문에 답을 미리 흘리지 마십시오.** "불량 있죠?"처럼 답을 정해 놓고 물으면 모델이
   끌려갑니다. 특히 개수를 묻는 질문에서 위험합니다.
4. **물어볼 것은 한 번에 묶어서 물어도 됩니다.** 한 번에 8개를 물어도 정확도가 떨어지지
   않았습니다. 하나씩 나눠 물으면 비용과 대기 시간만 늘어납니다.
5. **thinking 기능은 필요할 때만 켜십시오.** 기본값이 켜져 있어서, 끄지 않으면 영어로 된 생각
   과정이 먼저 길게 나오면서 정작 답변이 잘립니다. `vllm_ask.py`는 기본으로 꺼 둡니다.

## 설정

서버 주소는 이 저장소에 담지 않습니다. 사내 문서에서 값을 확인해 셸 설정에 넣으십시오.

```bash
export VLM_BASE_URL="http://<서버주소>:<포트>/v1"
export VLM_SSH_HOST="<ssh 호스트 별칭>"
export VLM_REMOTE_MEDIA="<서버에서 영상을 읽도록 허용된 폴더 경로>"
```

## 영상에 대해 질문하기 (평소 사용)

```bash
python3 vllm_ask.py ~/Videos/clip.mp4 "이 영상에서 로봇이 무엇을 하고 있어?"
python3 vllm_ask.py ~/Videos/clip.mp4 "설명해줘" --max-tokens 800 --think
```

내 컴퓨터에 있는 영상 파일을 주면 서버의 허용된 폴더로 자동 전송한 뒤 질문합니다. 서버가
지정된 폴더에 있는 영상만 읽도록 설정되어 있어서, 내 컴퓨터 경로를 그대로 적으면 읽히지
않습니다.

파이썬 기본 기능만 사용하므로 `openai` 같은 패키지를 따로 설치할 필요가 없습니다.

## 한계 측정하기 (기준 수치 갱신)

```bash
python3 vlm_probe.py temporal    # 얼마나 짧은 순간까지 보이는가
python3 vlm_probe.py sampling    # 영상 길이별로 초당 몇 장을 읽는가
python3 vlm_probe.py spatial     # 얼마나 작은 것까지 보이는가
python3 vlm_probe.py bundling --hard --reps 2   # 질문을 묶어서 물었을 때
python3 vlm_probe.py agreement --reps 2         # 실제 영상에서 따로 물을 때와 묶어 물을 때
python3 vlm_probe.py prompt --reps 2            # 질문의 길이 / 위치 / 미리 준 정보 / 언어
```

테스트 영상은 ffmpeg로 그때그때 만들어져 서버로 전송됩니다. 영상을 우리가 직접 만들기 때문에
정답을 처음부터 알고 있고, 따라서 준비할 영상 자료나 정답 파일이 필요하지 않습니다. `ffmpeg`와
서버로의 ssh 접속만 되면 됩니다.

## 측정 결과를 추가하는 방법

다시 측정했다면 `results/<측정한 날짜>_<모델 이름>.md`로 **새 파일을** 만드십시오. 기존 파일을
덮어쓰면 그 숫자가 어떤 설정에서 나온 것인지 알 수 없게 됩니다. 파일 맨 위에 모델 이름, vLLM
버전, 서버를 띄운 설정, 측정한 날짜를 남겨 주십시오.

## 필요한 것

- Python 3 (기본 기능만 사용)
- ffmpeg (한계 측정에만 필요)
- 추론 서버로의 ssh 접속 (영상을 보내는 데 사용)
