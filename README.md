# vlm-probe

사내 공용 추론 서버의 VLM 영상 이해 능력을 측정하고, 그 한계 안에서
안전하게 질의하기 위한 도구 모음입니다.

측정 결과는 `results/` 아래에 **모델과 측정일을 파일명에 박아** 보관합니다.
모델이나 vLLM 기동 옵션이 바뀌면 수치가 달라지므로, 반드시 해당 파일의 머리말에 적힌
조건과 지금 서버 설정이 같은지 확인하고 쓰십시오.

## 먼저 알아야 할 수칙

측정으로 확인된 사항입니다. 근거는 [최신 측정 결과](results/2026-09-18_qwen3.8-27b.md)에
있습니다.

1. **영상은 20초 이내로 잘라서 넣으십시오.** 20초까지는 2 fps로 샘플링되지만, 그보다 길면
   총 프레임이 포화되어 유효 샘플링이 떨어집니다. 180초 영상은 0.48 fps까지 내려갑니다.
2. **0.5초 미만의 순간을 찾는 데 쓰지 마십시오.** 접촉 순간이나 미끄러짐처럼 짧게 일어나는
   사건은 입력 프레임에 담기지 않아 원리적으로 잡히지 않습니다.
3. **질문에 답을 암시하지 마십시오.** "불량 있죠?"처럼 전제를 담아 물으면 모델이 끌려갑니다.
   특히 개수처럼 지각 근거가 약한 항목에서 위험합니다.
4. **검사 항목은 묶어서 한 번에 물어도 됩니다.** 항목을 8개까지 묶어도 정확도가 떨어지지
   않았습니다. 항목마다 호출을 나누면 비용과 지연만 늘어납니다.
5. **thinking 모드는 필요할 때만 켜십시오.** 기본값이 켜짐이어서, 끄지 않으면 영어 추론이
   먼저 나오면서 응답 토큰을 소진합니다. `vllm_ask.py`는 기본으로 꺼 둡니다.

## 설정

서버 주소는 저장소에 담지 않습니다. 사내 문서에서 값을 확인해 셸 설정에 넣으십시오.

```bash
export VLM_BASE_URL="http://<서버주소>:<포트>/v1"
export VLM_SSH_HOST="<ssh 호스트 별칭>"
export VLM_REMOTE_MEDIA="<서버의 allowed-local-media-path 경로>"
```

## 영상 질의 (일상 사용)

```bash
python3 vllm_ask.py ~/Videos/clip.mp4 "이 영상에서 로봇이 무엇을 하고 있어?"
python3 vllm_ask.py ~/Videos/clip.mp4 "설명해줘" --max-tokens 800 --think
```

로컬 파일을 주면 서버의 허용 디렉토리로 자동 전송한 뒤 질의합니다. 서버가
`--allowed-local-media-path`로 특정 디렉토리만 허용하기 때문에, 노트북 경로를 그대로
`file://`로 적으면 읽히지 않습니다.

파이썬 표준 라이브러리만 사용하므로 `openai` 패키지를 설치할 필요가 없습니다.

## 한계 측정 (베이스라인 갱신)

```bash
python3 vlm_probe.py temporal    # 시간 해상도 임계
python3 vlm_probe.py sampling    # 영상 길이별 유효 샘플링 fps
python3 vlm_probe.py spatial     # 공간 해상도 임계
python3 vlm_probe.py bundling --hard --reps 2   # 항목 수에 따른 정확도
python3 vlm_probe.py agreement --reps 2         # 라벨 없는 실영상 묶음 효과
python3 vlm_probe.py prompt --reps 2            # 프롬프트 길이/위치/전제/언어
```

자극 영상은 ffmpeg로 그 자리에서 생성되어 서버로 전송됩니다. 정답이 구성상 이미 정해져
있으므로 데이터셋도 라벨 파일도 필요하지 않습니다. `ffmpeg`와 서버로의 ssh 접근만 있으면
됩니다.

## 결과 추가 방법

측정을 다시 돌렸다면 `results/<측정일>_<모델>.md`로 새 파일을 만드십시오. 기존 파일을
덮어쓰면 그 숫자가 어느 설정 기준이었는지 잃어버립니다. 파일 머리말에 모델, vLLM 버전,
기동 옵션, 측정일을 남겨 주십시오.

## 요구 사항

- Python 3 (표준 라이브러리만 사용)
- ffmpeg (한계 측정에만 필요)
- 추론 서버로의 ssh 접근 (영상 전송에 사용)
