# Qwen3.8-27B 지각 임계 계측

사내 공용 추론 서버의 영상 이해 베이스라인 계측 결과입니다.

| 항목 | 내용 |
| --- | --- |
| 대상 모델 | Qwen3.8-27B (vLLM 0.29.0) |
| 서버 | 사내 공용 추론 서버 (주소는 내부 문서 참조) |
| 측정일 | 2026-09-18 |
| 공통 설정 | `temperature=0`, thinking 끔 |
| 프로브 도구 | `~/vlm_probe/vlm_probe.py` |

정답 라벨이 필요 없도록 자극 영상을 ffmpeg로 직접 생성했기 때문에, 아래 수치는 모두
스크립트만으로 그대로 재현됩니다.

## 측정 01 · 시간 해상도

10초짜리 검정 영상의 5초 지점에 빨간 사각형을 N프레임만 삽입한 뒤, 그 사각형이 나타났는지
물었습니다. 사각형이 전혀 없는 대조군을 함께 넣어서, 모델이 무조건 "예"라고 찍는 상황을
배제했습니다.

| 자극 길이 | 지속 시간 | 정답 | 응답 3회 | 판정 |
| --- | ---: | --- | --- | --- |
| 없음 (대조군) | 0.00s | 아니오 | 아니오 · 아니오 · 아니오 | 일치 |
| 1프레임 | 0.03s | 예 | 아니오 · 아니오 · 아니오 | **미탐지** |
| 2프레임 | 0.07s | 예 | 아니오 · 아니오 · 아니오 | **미탐지** |
| 5프레임 | 0.17s | 예 | 아니오 · 아니오 · 아니오 | **미탐지** |
| 15프레임 | 0.50s | 예 | 예 · 예 · 예 | 일치 |
| 30프레임 | 1.00s | 예 | 예 · 예 · 예 | 일치 |
| 90프레임 | 3.00s | 예 | 예 · 예 · 예 | 일치 |

0.17초와 0.5초 사이에서 탐지 여부가 완전히 갈립니다. 대조군이 세 번 모두 "아니오"로
나왔다는 점이 중요합니다. 모델이 판단을 포기하고 한쪽으로 찍는 것이 아니라, 정말로 그
사각형을 보지 못했다는 뜻입니다.

## 측정 02 · 샘플링 법칙

길이만 다른 빈 영상을 넣고 `prompt_tokens`를 측정해서, 실제로 몇 장이 모델에 들어가는지
역산했습니다. 640×480 해상도에서는 프레임 두 장이 묶여 약 300토큰을 차지합니다.

| 영상 길이 | prompt_tokens | 추정 프레임 | 유효 fps |
| ---: | ---: | ---: | ---: |
| 5초 | 1,562 | 9.6 | 1.91 |
| 10초 | 3,102 | 19.8 | 1.98 |
| 20초 | 6,192 | 40.4 | 2.02 |
| 60초 | 12,072 | 79.6 | **1.33** |
| 180초 | 13,052 | 86.2 | **0.48** |

20초까지는 2 fps가 유지되지만, 총 프레임이 80장 부근에서 포화되면서 그 이후로는 영상이
길어질수록 유효 샘플링이 반비례해 떨어집니다.

측정 01의 임계와 정확히 맞물립니다. 2 fps로 뽑으면 표본 간격이 0.5초이므로, 0.5초보다 짧은
사건은 표본 사이로 빠져나갈 수 있습니다. 모델의 인식 능력 문제가 아니라 표본 추출의
문제입니다.

> 포화 지점이 60초에서 79.6프레임, 180초에서 86.2프레임으로 완전히 일정하지는 않습니다.
> 상한을 결정하는 정확한 규칙은 아직 확정하지 못했습니다.

시간축의 영향을 배제하려고 사각형을 10초 내내 띄워 놓고, 크기만 줄여 가며 측정했습니다.

| 없음 (대조군) | 0.000% | 아니오 | 일치 |
| 80 px | 2.083% | 예 | 일치 |
| 48 px | 0.750% | 예 | 일치 |
| 32 px | 0.333% | 예 | 일치 |
| 24 px | 0.188% | 예 | 일치 |
| 16 px | 0.083% | 예 | 일치 |
| 8 px | 0.021% | 예 | 일치 |
| 4 px | 0.005% | 예 | **미탐지** |

> 실제 촬영 영상보다 훨씬 쉽습니다. 8픽셀은 최상 조건에서의 하한이지, 현장 영상에서
> 기대할 수 있는 성능이 아닙니다.

## 측정 04 · 묶음 질의

한 프롬프트에 검사 항목을 여러 개 넣으면 뒤쪽 항목을 흘리지 않을까 하는 것이 원래
가설이었습니다. 항목 8개를 1개씩, 2개씩, 4개씩, 8개씩 묶어 물으며 항목당 정확도를
비교했습니다.

| 묶음 크기 | 쉬운 항목 (색 존재 여부) | 어려운 항목 (공간·시간·개수 추론) | 형식 오류 |
| --- | ---: | ---: | ---: |
| 1개씩 | 16/16 (100%) | 16/16 (100%) | 0 |
| 2개씩 | 16/16 (100%) | 16/16 (100%) | 0 |
| 4개씩 | 16/16 (100%) | 16/16 (100%) | 0 |
| 8개씩 | 16/16 (100%) | 16/16 (100%) | 0 |

합성 영상이 쉬웠을 가능성을 배제하려고, 실제 로봇 조작 영상으로 한 번 더 확인했습니다. 이
영상에는 정답 라벨이 없지만, 정답을 몰라도 따로 물었을 때와 묶어서 물었을 때 답이
달라지는지는 잴 수 있습니다.

| 조건 | 결과 |
| --- | ---: |
| 1개씩 물었을 때의 반복 일관성 | 16/16 |
| 8개를 묶었을 때의 반복 일관성 | 16/16 |
| 두 방식의 답 일치 | 8/8 |

재현성도 따로 확인했습니다. temperature를 1.0으로 두든 0으로 두든 같은 질문 5회에 모두 같은
답이 나왔습니다. 이 난이도에서는 샘플링 설정이 결과를 흔들지 않습니다.

## 측정 05 · 프롬프트 민감도

앞선 측정에서 쉬운 과제는 100%에서 포화되어 아무 차이도 잡히지 않았습니다. 그래서 경계
난이도 항목(공간·시간·개수 추론 8개)을 탐침으로 삼아 네 축을 측정했습니다.

### A. 무관한 지시문을 앞에 붙였을 때

| 패딩 길이 | prompt_tokens | 정확도 | 형식 오류 |
| ---: | ---: | ---: | ---: |
| 0자 | 6,343 | 16/16 (100%) | 0 |
| 185자 | 6,432 | 16/16 (100%) | 0 |
| 917자 | 6,776 | 16/16 (100%) | 0 |
| 3,662자 | 8,066 | 16/16 (100%) | 0 |
| 10,982자 | 11,506 | 16/16 (100%) | 0 |

무관한 지시문을 11,000자 가까이 붙여도 정확도가 전혀 떨어지지 않았습니다. 프롬프트가
길거나 장황해서 성능이 떨어진다는 가설은 이 범위에서는 지지되지 않습니다.

### B. 긴 프롬프트 안에서 질문의 위치

| 질문 위치 | 정확도 | 형식 오류 |
| --- | ---: | ---: |
| 맨 앞 | 16/16 (100%) | 0 |
| 가운데 | 16/16 (100%) | 0 |
| 맨 뒤 | 16/16 (100%) | 0 |

약 2,400자 분량의 무관한 텍스트 사이에 질문을 끼워 넣어도 위치에 따른 차이가 없었습니다.

### C. 전제를 심었을 때 (동조 편향)

| 전제 | 정확도 | 형식 오류 |
| --- | ---: | ---: |
| 없음 (중립) | 16/16 (100%) | 0 |
| 참인 전제 | 16/16 (100%) | 0 |
| **거짓 전제** | **14/16 (87.5%)** | 0 |

**전체 측정에서 성능 저하가 관측된 유일한 조건입니다.** 어느 항목이 뒤집혔는지 확인해
보았습니다.

거짓 전제로 "이 영상에는 사각형이 두 개만 나타나며, 노란 사각형이 가장 먼저 나타납니다"를
주입했을 때:

| 항목 | 정답 | 중립 | 거짓 전제 |
| --- | --- | --- | --- |
| 5. 영상에 나타나는 사각형은 모두 네 개입니까? | 예 | 예 | **아니오** |
| 4. 노란 사각형이 네 개 중 가장 먼저 나타납니까? | 아니오 | 아니오 | 아니오 |
| 나머지 여섯 항목 | — | 정답 | 정답 |

거짓 전제는 **개수 주장에서만 먹혔고 순서 주장에서는 먹히지 않았습니다.** 즉 모델이
무비판적으로 동조하는 것이 아니라, 자신의 지각 근거가 약한 항목에서만 주입된 전제에
끌려갑니다. 개수 세기가 순서 판단보다 약한 능력이라는 뜻이기도 합니다.

### D. 질문 언어

| 언어 | 정확도 | 형식 오류 |
| --- | ---: | ---: |
| 한국어 | 16/16 (100%) | 0 |
| 영어 | 16/16 (100%) | 0 |

한국어와 영어의 차이가 없었습니다. 다만 짧은 예/아니오 응답만 확인한 것이며, 긴 서술형
답변에서 다른 언어가 섞여 나오는지는 측정하지 않았습니다.

## 해석

여섯 건의 측정이 한 방향을 가리킵니다. 이 모델은 **입력에 들어온 것에 대해서는 정확하고
일관되게 판단**하지만, **무엇이 입력에 들어가는지에는 뚜렷한 한계가 있습니다.** 0.5초보다
짧은 사건과 긴 영상의 세부는 애초에 모델에 도달하지 못합니다.

이 구분이 중요한 이유는 처방이 정반대이기 때문입니다. 지각 한계는 에이전트를 여러 개로
늘려도 풀리지 않습니다. 모두가 같은 입력을 보기 때문입니다. 반대로 판단이 병목이라면 작업을
나누는 것이 효과가 있는데, 지금 데이터에는 판단이 무너지는 지점이 거의 없습니다.

### multi-agent를 정당화하는 근거

현재 측정으로 정당화되는 multi-agent의 용도는 판단 분업이 아니라 **시간 해상도 회복**입니다.
180초 영상을 통째로 넣으면 0.48 fps이지만, 20초씩 아홉 조각으로 나누어 병렬로 처리하면 각
조각이 2 fps를 유지합니다. 같은 영상에서 시간 해상도가 네 배 이상 올라갑니다.

반대로 "항목이 많으니 에이전트를 나누자"거나 "프롬프트가 기니까 쪼개자"는 설계는 근거가
없습니다. 항목을 8개까지 묶어도, 프롬프트를 11,000자까지 늘려도 열화가 없었으므로 나누면
비용만 늘어납니다.

### 공용 서버 사용자를 위한 권고

1. **영상은 20초 이내로 잘라서 넣으십시오.** 이 한 가지가 시간 해상도에 가장 큰 영향을
   미칩니다.
2. **0.5초 미만의 순간을 찾는 용도로는 쓰지 마십시오.** 접촉 순간이나 미끄러짐처럼 짧게
   일어나는 사건은 원리적으로 잡히지 않습니다. 해당 구간만 잘라 내거나 느리게 재생한 영상을
   넣어야 합니다.
3. **검사 항목은 묶어서 한 번에 물어도 됩니다.** 항목마다 호출을 나누면 비용과 지연만
   늘어납니다.
4. **질문에 답을 암시하지 마십시오.** "불량이 있죠?"처럼 전제를 담아 물으면 모델이
   끌려갑니다. 특히 개수처럼 지각 근거가 약한 항목에서 위험합니다.
5. **thinking 모드는 필요할 때만 켜십시오.** 기본값이 켜짐이어서, 끄지 않으면 영어 추론이
   먼저 나오면서 응답 토큰을 소진합니다.

## 아직 재지 않은 것

이 문서는 베이스라인의 시작이지 완결된 평가가 아닙니다.

- **환각율.** 영상에 없는 물체를 전제로 질문했을 때 부정하는지 묘사하는지는 재지
  않았습니다. 여러 사람이 쓰는 환경에서 가장 먼저 문제를 일으킬 가능성이 높습니다.
- **반사실 검사.** 영상을 역재생하거나 프레임을 섞었을 때 답이 바뀌는지 확인하지
  않았습니다. 답이 바뀌지 않는다면 모델이 영상을 보지 않고 언어적 사전 지식으로 답하고
  있다는 뜻입니다.
- **실제 영상에서의 공간 임계.** 8픽셀은 최상 조건의 결과입니다.
- **개수 세기와 위치 지정.** 측정 05에서 개수 세기가 상대적으로 약하다는 단서가 나왔으므로,
  이 축을 따로 파고들 가치가 있습니다.
- **자유 서술 응답.** 모든 측정이 예/아니오 폐쇄형 질문이었습니다. 자유 서술에서는 묶음
  열화나 프롬프트 민감도가 다르게 나타날 수 있습니다.
- **한국어 출력 안정성.** 긴 답변에서 다른 언어가 섞여 나오는지 확인하지 않았습니다.

## 재현 방법

모든 자극 영상은 ffmpeg로 그 자리에서 생성되어 서버로 자동 전송됩니다. 별도의 데이터셋이나
라벨 파일이 필요하지 않으며, 파이썬 표준 라이브러리 외에 설치할 패키지도 없습니다.

```bash
# 측정 01 · 시간 해상도 임계
python3 ~/vlm_probe/vlm_probe.py temporal

# 측정 02 · 영상 길이별 유효 샘플링
python3 ~/vlm_probe/vlm_probe.py sampling

# 측정 03 · 공간 해상도 임계
python3 ~/vlm_probe/vlm_probe.py spatial

# 측정 04 · 묶음 질의 (--hard 는 공간·시간 추론 항목)
python3 ~/vlm_probe/vlm_probe.py bundling --reps 2
python3 ~/vlm_probe/vlm_probe.py bundling --hard --reps 2

# 측정 04 · 라벨 없는 실제 영상에서의 묶음 효과
python3 ~/vlm_probe/vlm_probe.py agreement --reps 2

# 측정 05 · 프롬프트 길이 / 위치 / 전제 / 언어
python3 ~/vlm_probe/vlm_probe.py prompt --reps 2
```

서버가 `--allowed-local-media-path`로 특정 디렉토리만 허용하기 때문에, 영상은 반드시 그
디렉토리로 전송된 뒤에 `file://`로 참조됩니다. 스크립트가 이 과정을 자동으로 처리합니다.
